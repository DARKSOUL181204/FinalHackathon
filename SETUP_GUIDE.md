# Defense Logistics Management System — Setup & Run Guide

This guide walks you through setting up and running the project from scratch after downloading the ZIP from GitHub.

---

## 1. Prerequisites

Make sure the following tools are installed on your machine:

1. **Java JDK 21+**
   - Check with: `java -version`
2. **Apache Maven 3.8+**
   - Check with: `mvn -version`
3. **MySQL Server 8.x or 9.x**
   - Ensure MySQL is running on `localhost:3306`.
4. **Python 3** (Optional, used only for running the mock data seed script `seed_data.py`).

---

## 2. Extract and Verify Directory Structure

After extracting the downloaded ZIP file, open a terminal in the project root folder.

Verify that the folder structure looks like this:
```text
DefenceProject-main/
├── pom.xml
├── start-all.sh
├── start-all.ps1
├── seed_data.py
├── resource-service/
│   ├── pom.xml
│   └── src/
├── inventory-service/
│   ├── pom.xml
│   └── src/
├── request-service/
│   ├── pom.xml
│   └── src/
└── frontend-ui/
    ├── pom.xml
    └── src/
```

> **Note for macOS Users:** If macOS Finder created duplicate folder names with timestamps (e.g. `resource-service 8.49.03 AM`), rename them back to `resource-service` and `request-service`.

## 3. Database Configuration

All 3 backend services connect to MySQL on `localhost:3306`.

### Option A: Create MySQL User (Recommended — No Code Changes)
Run this SQL command in MySQL (via MySQL Workbench, terminal `mysql -u root -p`, etc.):

```sql
CREATE USER IF NOT EXISTS 'nidhi'@'localhost' IDENTIFIED BY 'nidhip414';
GRANT ALL PRIVILEGES ON *.* TO 'nidhi'@'localhost';
FLUSH PRIVILEGES;
```

### Option B: Use Your Own MySQL Credentials
If you prefer using your own MySQL credentials (e.g. `root` and your password), update the datasource username and password in these 3 files:
1. `resource-service/src/main/resources/application.properties`
2. `inventory-service/src/main/resources/application.properties`
3. `request-service/src/main/resources/application.properties`

Update these lines:
```properties
spring.datasource.username=YOUR_MYSQL_USERNAME
spring.datasource.password=YOUR_MYSQL_PASSWORD
```

> **Note on Database Creation:** You do **not** need to manually create the databases. The JDBC URLs have `createDatabaseIfNotExist=true`. The schemas (`resource_db`, `inventory_db`, `request_db`) and tables will be auto-generated by Flyway migrations on startup.

---

## 4. Build the Project

From the project root directory, build and package all modules:

```bash
mvn clean install -DskipTests
```

You should see `BUILD SUCCESS` for all 4 modules.

---

## 5. Starting All Services

All 4 services need to be running.

### Method 1: Using the Startup Scripts

#### On macOS / Linux:
```bash
chmod +x start-all.sh
./start-all.sh
```

#### On Windows (PowerShell):
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\start-all.ps1
```

---

### Method 2: Running in Separate Terminal Windows

If you prefer starting each service individually (recommended for seeing live logs during development):

#### Terminal 1 — Resource Service (Port 9191)
```bash
cd resource-service
mvn spring-boot:run
```

#### Terminal 2 — Inventory Service (Port 9192)
```bash
cd inventory-service
mvn spring-boot:run
```

#### Terminal 3 — Request Service (Port 9193)
```bash
cd request-service
mvn spring-boot:run
```

#### Terminal 4 — Frontend UI (Port 8080)
```bash
cd frontend-ui
mvn spring-boot:run
```

---

### Method 3: Running Built JAR Files Directly
For fast startup without running Maven in the background:

```bash
# Terminal 1
java -jar resource-service/target/resource-service-1.0.0-SNAPSHOT.jar

# Terminal 2
java -jar inventory-service/target/inventory-service-1.0.0-SNAPSHOT.jar

# Terminal 3
java -jar request-service/target/request-service-1.0.0-SNAPSHOT.jar

# Terminal 4
java -jar frontend-ui/target/frontend-ui-1.0.0-SNAPSHOT.jar
```

## 8. Common Troubleshooting

1. **Port Already In Use (`Address already in use`)**:
   Check what is occupying ports `8080`, `9191`, `9192`, or `9193`:
   - macOS / Linux: `lsof -i :8080` (or `9191`, `9192`, `9193`) and kill using `kill -9 <PID>`
   - Windows: `netstat -ano | findstr :8080` and `taskkill /PID <PID> /F`

2. **Access Denied for MySQL (`Access denied for user 'nidhi'@'localhost'`)**:
   Follow Step 3 to create the user or update the credentials in the `application.properties` files to match your local MySQL configuration.

3. **Child Module Not Found**:
   Ensure directory names inside the project root are strictly:
   - `resource-service`
   - `inventory-service`
   - `request-service`
   - `frontend-ui`
